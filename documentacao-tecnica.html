📋 Visão Geral

O que é: O Dunder Mifflin é um sistema de orquestração de agentes AI (LLMs) que permite criar, gerenciar e executar tarefas através de múltiplos agentes especializados, com ciclo de iteração automático (Ralph Loop) para refinamento contínuo.

Funcionalidades Principais

  • Gerenciamento de Agentes: 63+ agentes especializados em 10 departamentos
  • Missões: Sistema de tarefas com atribuição automática de agentes
  • Ralph Loop: Iteração automática até completude com tracking de custos
  • Dashboard Web: Interface visual para monitoramento em tempo real
  • API REST: Integração completa via HTTP/JSON
  • Cron Jobs: Execução automática e notificações

🔄 Ralph Loop - Sistema de Iteração

Como Funciona

O Ralph Loop é o coração do sistema. Ele permite que tarefas complexas sejam executadas em múltiplas iterações com um agente AI, até que o objetivo seja alcançado.

Conceito: Em vez de uma única chamada ao LLM, o loop executa iterações sucessivas, onde cada resposta é analisada e, se necessário, uma nova iteração é iniciada com contexto atualizado.

Fluxo do Loop

  1. Criação: Loop criado com status='running' e current_iteration=0
  2. Execução: Executor busca loops com iteration=0
  3. Iteração: Agente recebe prompt + histórico e responde
  4. Validação: Verifica se contém <RALPH_COMPLETE>
  5. Se completo: Salva resultado, marca como completed
  6. Se incompleto: Incrementa iteração, atualiza histórico, repete

Sinal de Completude

# O agente DEVE incluir no final da resposta: <RALPH_COMPLETE> # Exemplo: def minha_funcao(): """Docstring""" pass # Testes passaram ✅ <RALPH_COMPLETE>

Queries Úteis

-- Listar loops completados hoje SELECT loop_code, agent_slug, current_iteration, total_cost_usd FROM ralph_loops WHERE status = 'completed' AND date(completed_at) = date('now') ORDER BY completed_at DESC; -- Custos por agente SELECT agent_slug, COUNT(*) as total, SUM(total_cost_usd) as custo_total FROM ralph_loops WHERE status = 'completed' GROUP BY agent_slug;

Troubleshooting

Problema: API não responde
Solução: Verificar se porta 3003 está livre: lsof -i :3003
Problema: Loops não executam
Solução: Verificar cron job: openclaw cron list
Problema: Agente fica perguntando ao invés de entregar
Solução: Verificar prompt em loops/prompts/<agente>-prompt.md
