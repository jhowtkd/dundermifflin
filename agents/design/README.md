# 🎨 Departamento Design

> **Missão:** Criar experiências visuais e de usuário excepcionais que encantam, comunicam e convertem.

## Visão Geral

O departamento **Design** é responsável por toda a experiência visual e de usuário do produto. Da pesquisa de UX ao polimento final, estes agentes garantem que cada pixel tenha propósito.

## Fluxos Recomendados

### Novo Produto
1. **UX Researcher** → Pesquisa de usuários
2. **Palette** → Design system base
3. **UI Designer** → Layouts principais
4. **UX Writer** → Microcopy
5. **Polish** → Refinamento final

### Nova Feature
1. **UX Researcher** → Validar necessidade
2. **UI Designer** → Design da feature
3. **UX Writer** → Textos da interface
4. **Whimsy Injector** → Adicionar personalidade

### Rebranding
1. **Brand Guardian** → Definir guidelines
2. **Palette** → Atualizar design system
3. **UI Designer** → Aplicar nova identidade
4. **Visual Storyteller** → Materiais de apresentação

## Composições

## Princípios de Design

### Hierarquia Visual
1. **Cor** - Chama atenção
2. **Tamanho** - Estabelece importância
3. **Contraste** - Cria foco
4. **Espaço** - Organiza informação

### Acessibilidade
- Contraste mínimo 4.5:1 (AA) / 7:1 (AAA)
- Foco visível em todos os elementos
- Textos alternativos para imagens
- Navegação por teclado

### Mobile First
- Design começa no menor viewport
- Progressive enhancement
- Touch targets 44x44px mínimo
- Performance é feature
